# 普羅米修斯之火 v3.0 - 生產級 AI 作戰平台

本專案是一個全功能的 AI 金融分析作戰平台，具備從前端 UI 驅動後端核心演算法、執行非同步分析任務，並將結果即時視覺化的完整能力。

其核心架構採用了生產級的「API 伺服器 + 工人蜂群」模式，確保了系統的高可用性、高擴展性與高吞吐量。

## 核心特性

- **動態 Web 指揮中心**: 提供一個即時、互動式的 Web 介面，用於下達指令和監控態勢。
- **非同步任務架構**: 基於任務佇列，能夠處理長時間運行的 AI 分析任務而不會阻塞介面。
- **生產級服務管理**: 使用 `gunicorn` 統一管理 API 伺服器，並建立「工人蜂群」以並行處理多個任務。
- **雙模式作戰系統**: 可在「生產模式」（使用真實網路數據）和「作戰演習模式」（使用模擬數據）之間切換，兼顧真實性與開發速度。
- **全方位監控**: 具備即時的系統資源監控與完整的歷史任務追蹤能力。

## 如何啟動作戰

### 1. 環境設定

本專案使用 `poetry` 進行依賴管理。請確保已安裝 `poetry`。

```bash
# 安裝所有依賴
poetry install
```
### 2. 啟動生產級服務
執行以下指令，將會一次性啟動由 Gunicorn 管理的 API 伺服器集群，以及一個由多個工人程序組成的「工人蜂群」。
```bash
poetry run python run.py start_services
```
服務啟動後，即可在瀏覽器中訪問 http://127.0.0.1:8000 進入作戰指揮中心。

### 3. 執行快速整合測試 (作戰演習模式)
為了進行快速的開發驗證，我們提供了「作戰演習模式」。執行以下指令將會在此模式下，運行我們的全自動化整合測試，並在十幾秒內完成。
```bash
# 執行我們最終的、基於 pathlib 的高可用性測試腳本
poetry run python test_sentinel_robustness.py
```
