# 普羅米修斯之火 v9.1.0 - AI 驅動的量化研究框架

**普羅米修斯之火** 是一個專為金融市場設計的、生產級的 AI 量化研究框架。它提供了一個從數據獲取、特徵工程、策略回測到結果視覺化的完整解決方案，旨在加速從研究到實戰的過程。

本框架採用了業界領先的「API 伺服器 + 分散式工人」架構，確保了系統在處理大規模、長時間的計算任務時，依然保持高效、穩定與可擴展。

## 核心特性

- **動態 Web 指揮中心**: 一個以 FastAPI 和 Plotly 打造的互動式 Web 介面，讓您能即時下達分析指令、監控系統狀態，並將複雜的金融數據以圖表化的方式呈現。
- **非同步任務佇列**: 基於 `aiosqlite` 的輕量級任務佇列，允許您提交耗時的 AI 分析與回測任務，而不會阻塞主介面，實現真正的非同步作戰。
- **生產級服務架構**: 使用 `gunicorn` 作為 WSGI 伺服器，統一管理 FastAPI 應用，並透過 `real_worker.py` 建立可水平擴展的「工人蜂群」，實現高併發的任務處理能力。
- **可擴展的數據管線**: 模組化的數據處理管線 (`pipeline`)，讓您可以輕易地客製化或擴展特徵工程的步驟，以應對多變的市場。
- **整合式數據引擎**: 內建多種數據客戶端 (`yfinance`, `fredapi` 等)，並透過 `duckdb` 進行高效的數據倉儲與查詢，簡化了數據管理的複雜性。
- **雙模式作戰系統**:
    - **生產模式**: 連接真實世界的金融數據 API，進行實盤等級的分析與研究。
    - **演習模式**: 使用預存的模擬數據 (`mock_data_engine`)，讓您在開發與測試階段能進行快速、可重複的實驗，大幅提升開發效率。

## 技術棧

本框架融合了多種現代化的 Python 技術，以達到生產級的效能與可靠性：

- **核心框架**: `FastAPI`, `Typer`, `Gunicorn`
- **數據處理與分析**: `Pandas`, `Numpy`, `DuckDB`, `VectorBT`, `DEAP`, `Pandas-TA`
- **資料獲取**: `YFinance`, `FredAPI`, `Requests`
- **異步與排隊**: `AioSQLite`
- **前端與視覺化**: `Plotly`, `Rich`
- **測試與品質**: `Pytest`, `Playwright`, `Ruff`

## 架構概覽

系統的核心是一個由 **FastAPI** 驅動的 **Query Gateway (查詢閘道)**，它負責接收來自前端的指令。當一個需要大量計算的任務（例如：生成數千個市場的特徵因子）被提交時，閘道會將該任務放入一個基於 **SQLite** 的任務佇列中。

與此同時，一個或多個 **Worker (工人)** 程序在背景中不斷地監聽這個佇列。一旦發現新任務，工人會立即領取並開始執行。這種架構的優勢在於：

1.  **非阻塞**: 前端介面在提交任務後可以立即響應，使用者無需等待。
2.  **高擴展性**: 當計算需求增加時，只需簡單地增加工人程序的數量，即可線性提升系統的處理能力。
3.  **高可靠性**: 即使某個工人程序因意外而崩潰，任務佇列中的任務依然存在，可以由其他工人接手完成。

```
+-----------------+      +---------------------+      +-----------------+
|   Web Browser   |----->|  FastAPI Gateway    |----->|   Task Queue    |
| (Dashboard.html)|      | (query_gateway.py)  |      | (sqlite_queue.py)|
+-----------------+      +---------------------+      +-------+---------+
                                                               |
                                                               |
+-----------------+      +-----------------+      +------------+----------+
| Worker 1        |<-----| Worker 2        |<-----| ... (More Workers) ...|
| (real_worker.py)|      | (real_worker.py)|      |                       |
+-----------------+      +-----------------+      +-----------------------+
```

## 如何啟動

### 1. 環境設定

本專案使用 `poetry` 進行依賴管理。請確保您已安裝 `poetry`。

```bash
# 安裝所有專案依賴
poetry install
```

### 2. 啟動服務

執行以下指令，將會一次性啟動由 Gunicorn 管理的 API 伺服器，以及背景的工人程序。

```bash
# 啟動 FastAPI 伺服器與工人
poetry run python -m src.prometheus.cli.main services start
```

服務啟動後，您可以在瀏覽器中訪問 `http://127.0.0.1:8000` 進入作戰指揮中心。
